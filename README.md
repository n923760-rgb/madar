# MADAR — مدار

> بس أرسلها لمدار.

Arabic-first personal organizer for the Saudi market, delivered through a Telegram Bot and Telegram Mini App.

## Product

Capture → Understand → Organize → Remind.

Users can capture text, voice, images, screenshots, PDFs, files, and forwarded messages. MADAR proposes structured actions for review and confirmation.

## Current phase

**Product UX and UI design only.** Production backend, frontend, and database implementation begin after design approval. This repository is initialized for project documentation and design work.

## Approved references

- MADAR Product & UX Master Specification v2.1
- MADAR UX Architecture v1

The authoritative documents will be imported with their approval status preserved. Review recommendations remain proposals until explicitly accepted.

## Engineering direction

Planned stack: Python/FastAPI, aiogram, PostgreSQL, SQLAlchemy/Alembic, Redis, private object storage, Next.js, TypeScript, and Tailwind.

AI proposes actions; validated application logic controls persistence. User data and attachments remain private.
